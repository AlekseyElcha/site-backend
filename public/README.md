# Фронтенд для веб-сервиса обращений

Тонкий клиент на React + TypeScript для веб-сервиса по приему обращений и ответам на них.

## Технологии

- React 18
- TypeScript
- Vite
- React Router
- Date-fns

## Установка

```bash
npm install
```

## Запуск

Убедитесь, что бэкенд запущен на порту 8000, затем:

```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:3000

## Сборка

```bash
npm run build
```

## Структура проекта

- `/src/components` - UI компоненты
- `/src/pages` - Страницы приложения
- `/src/contexts` - React контексты
- `/src/services` - API сервисы
- `/src/types` - TypeScript типы
- `/src/utils` - Утилиты

## Функциональность

- Аутентификация через email с одноразовым кодом
- Страница пользователя для просмотра своих обращений
- Страница администратора для управления всеми обращениями
- Создание новых обращений
- Ответы на обращения (администратор)
- Изменение статусов обращений (администратор)
